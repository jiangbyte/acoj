# 校园 Portal UI 去商业化 / 去力扣感

## 目标
学校内 OJ：练习 / 知识点 / 课程路径 / 今日练习。保留题单、计划、每日题、统计 API，改呈现与文案。

## 主题
- 主色对齐 admin `theme.json`：`#1677FF` / hover `#4096FF`
- 难度色用 Ant Design 语义色：绿 `#52c41a` / 橙 `#faad14` / 红 `#ff4d4f`（活力、不发闷）
- `panel`：轻描边 + 淡蓝阴影，圆角 10，避免厚边塑料感

## 页面
- 首页：删名企、假社交、无效 Tab；公告 + 题目推荐；右栏「今日练习」
- 题库 / 路径：扁平入口 + 主色强调边，轻微上浮，不用彩虹营销渐变
- 文案学校化：今日练习 / 连续练习 / 练习路径 / 进阶专题
