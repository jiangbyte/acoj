# ACOJ 模块功能设计

> 本文档在现有工程（`server` / `admin` / `portal`）能力之上，结合 OJ 业务设计参考，整理为可落地的**功能模块说明**（非数据库设计）。
>
> - **平台底座**：工程已具备，OJ 业务复用，不重复建设。
> - **OJ 业务**：待建设，按阶段交付。
> - 端侧约定：用户侧 → Portal（React）；管理 / 教师侧 → Admin（Vue）；API → `/api/v1/portal/*`、`/api/v1/admin/*`。

---

| OJ 核心 | 题库、提交与判题、竞赛、题单 | **P0 设计已定** / 竞赛题单待建 | Portal + Admin |

## 一、平台底座（已有，OJ 复用）

以下能力已在 HEI 脚手架中实现，OJ 业务直接扩展，**不另起一套账号 / 权限 / 消息 / 运维**。

### 1.1 认证与会话

| 功能点 | 说明 | 端 |
|--------|------|----|
| 账号 / 邮箱 / 手机号登录 | 密码 RSA 传输、验证码、失败锁定与限流 | Admin / Portal |
| 注册 | Portal 用户注册 | Portal |
| 找回 / 重置密码 | 邮箱或手机验证码 | Admin / Portal |
| 第三方登录 | JustAuth（GitHub / 微信等，可配置） | Portal（主） |
| 会话管理 | Cookie / Header；刷新与登出；在线踢出 | Admin |
| 账号注销 | 冷静期说明与确认 | Portal / Admin |

### 1.2 组织与权限（IAM）

| 功能点 | 说明 | 端 |
|--------|------|----|
| 账号管理 | 账号 CRUD、身份标识、三方绑定查看 | Admin |
| 角色与授权 | 角色 CRUD；菜单 / 按钮 / API 授权 | Admin |
| 组织架构 | 部门 / 用户组 / 岗位 | Admin |
| 资源与客户端资源 | 动态菜单与权限树；多客户端模型 | Admin |
| 角色建议（OJ） | 在现有 RBAC 上增加 `教师` / `题目管理员` 等角色，不新建权限体系 | Admin |

### 1.3 个人中心与实名

| 功能点 | 说明 | 端 |
|--------|------|----|
| 公开资料 | 头像、昵称、简介；公开主页卡片 | Portal / Admin |
| 安全设置 | 改密、手机 / 邮箱绑定、三方绑定 | Portal / Admin |
| 实名认证 | 提交、审核、敏感字段脱敏 | Portal 提交 · Admin 审核 |
| OJ 扩展字段（待建） | 学校、年级、语言栈、刷题统计入口挂到个人主页 | Portal |

### 1.4 消息与内容运营

| 功能点 | 说明 | 端 |
|--------|------|----|
| 公告 / 通知 | 发布、置顶、撤回；用户收件箱、已读未读 | Admin 运营 · Portal 阅读 |
| Banner | 首页运营位 | Admin · Portal |
| 意见反馈 | 用户提交与进度查看；后台处理 | Portal · Admin |
| OJ 消息扩展（待建） | 在通知体系上增加竞赛提醒、判题完成、互动类消息类型 | — |

### 1.5 系统运维

| 功能点 | 说明 | 端 |
|--------|------|----|
| 字典 / 动态配置 | 含敏感项加密；OJ 判题默认时限等可走配置 | Admin |
| 对象存储 | S3 兼容（MinIO / OSS）；题目数据包、课件、证书等复用 | Admin |
| 文件管理 | 上传、预签名、下载 | Admin / Portal |
| 任务调度 | 内置 `sys_job`；可用于榜单结算、证书生成、重判任务 | Admin |
| 操作审计 / 登录日志 | 全链路审计 | Admin / Portal（我的） |
| 工作台 | 概览与快捷入口；后续挂 OJ 运营指标 | Admin |
| 代码生成 | 单表 / 树表 / 主子表；加速 OJ CRUD 脚手架 | Admin |

## 二、题库模块（待建）

### 2.1 题目列表与筛选

| 功能点 | 说明 |
|--------|------|
| 题目列表 | 分页；列表 / 卡片视图 |
| 多维筛选 | 难度、标签、来源、状态（已 AC / 未 AC / 未尝试）、通过率 |
| 搜索 | 题号、标题、标签关键词 |
| 排序 | 题号、通过率、提交数、难度 |
| 收藏 | 个人收藏夹 |
| 错题本 | 自动归集做过但未 AC 的题目 |

### 2.2 题目详情

| 功能点 | 说明 |
|--------|------|
| 题面展示 | Markdown / 富文本；数学公式（KaTeX） |
| I/O 与样例 | 输入输出规范、样例数据 |
| 提示与标签 | 附加说明、关联标签 |
| 关联跳转 | 题解文章、相关题目、题目讨论 |

### 2.3 提交与判题（Portal）

| 功能点 | 说明 |
|--------|------|
| 代码编辑器 | 语法高亮、补全、主题 |
| 语言选择 | C / C++ / Java / Python / Go / Rust 等 |
| 提交入队 | 写入判题队列 |
| 实时结果 | WebSocket / SSE 推送进度与终态 |
| 结果展示 | AC / WA / TLE / MLE / RE / CE 等 |
| 测试点详情 | 各点时间、内存、状态（按赛制 / 权限可见） |
| 历史提交 | 查看、复制代码；可选公开分享链接 |

### 2.4 题目管理（Admin）

| 功能点 | 说明 |
|--------|------|
| 题目 CRUD | 创建 / 编辑 / 逻辑删除 |
| 测试数据 | 上传 / 下载 / 维护测试用例包 |
| 标签体系 | 标签 CRUD；可选父子层级；批量打标 |
| 审核流 | 用户供题 / 改题需审核；记录意见 |
| 批量导入导出 | ZIP / JSON 批量题目 |

在现有工作台 / 运维菜单旁扩展，**不新建独立后台工程**。

| 区块 | 功能点 |
|------|--------|
| OJ 总览 | 用户 / 题目 / 提交 / AC / 比赛趋势；判题队列长度与等待 |
| 判题运维 | 提交记录、单题 / 批量重判、人工评测、判题节点状态 |
| 内容审核 | 供题审核、讨论 / 文章审核（与现有公告、反馈并列） |

用户封禁、角色分配等继续使用 **IAM 账号 / 角色**，不在 OJ 模块重复实现。

## 十一、建议实施阶段

| 阶段 | 目标 | 模块 |
|------|------|------|
| **P0** | 可刷题 | 题库（列表 / 详情 / 管理）+ 提交判题 + 基础个人做题统计 + **生产级多执行机调度**（见下方设计文档） |
| **P1** | 可办赛 | 竞赛（报名 / 赛中 / 榜单冻结）+ 判题运维（重判 / 队列） |
| **P2** | 可教学 | 题单 + 课程作业 |
| **P3** | 可社区 | 讨论 + 文章广场 + 互动通知 |
| **P4** | 可扩展 | 排行榜、团队、开放 API、数据分析 / 证书 |

### P0 设计文档（已定稿）

生产原则摘要：SparkSandbox **只执行**；AC/WA 在 ACOJ 计算；测例用 `oj_problem_case`（**不**复用 `sys_file`）；执行机登记于 `oj_judge_node`，含探活 / 熔断 / 排水 / 租约换机；判题任务队列使用 **RabbitMQ**（不用 Redis 排队）。

| 文档 | 内容 |
|------|------|
| [p0-数据库设计.md](./p0-数据库设计.md) | `oj_*` 全表 DDL、枚举、测例版本化、派发审计 |
| [p0-判题对接.md](./p0-判题对接.md) | RabbitMQ 队列、加权调度、熔断换机、租约、业务裁决 |
| [p0-判题运维.md](./p0-判题运维.md) | 拓扑、密钥、SLO、告警、容量、对账与故障演练 |

## 十二、模块关系（功能视角）

```
用户 ──▶ Portal
           ├─ 认证 / 个人中心 / 消息 / 公告     （已有）
           ├─ 题库 ──提交──▶ 判题结果
           ├─ 竞赛 / 题单 / 课程
           └─ 讨论 / 文章 / 排行榜

教师/管理员 ──▶ Admin
           ├─ IAM / 配置 / 文件 / 审计 / 工作台 （已有）
           ├─ 题目 / 标签 / 审核 / 测试数据
           ├─ 竞赛管理 / 判题运维
           └─ 课程管理 / 内容审核
```
